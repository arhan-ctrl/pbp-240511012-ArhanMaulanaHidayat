# Analisis Karakteristik Platform

| Aspek | Web | Desktop | Mobile |
| :--- | :--- | :--- | :--- |
| **Arsitektur** | Client-Server (Front-end di browser, Back-end di server) | Monolitis / Standalone (Akses langsung ke OS/Hardware) | Client-Server / Standalone dengan optimasi hemat daya & memori |
| **Bahasa Utama** | HTML, CSS, JavaScript, TypeScript | Java, C#, C++, Python | Kotlin, Swift, Java, Dart (Flutter) |
| **Distribusi** | URL/Domain via Internet (Tanpa Instalasi) | Executable File (.exe, .msi, .dmg, .deb) | Application Store (Google Play Store, App Store, APK) |
| **Keunggulan** | Multi-platform instant, tidak perlu instalasi, pembaharuan terpusat | Performa tinggi, akses hardware penuh, dapat berjalan offline penuh | Portabel, mendukung sensor internal (GPS, kamera, akselerometer), push notification |
| **Keterbatasan** | Ketergantungan jaringan, akses fitur hardware terbatas demi keamanan | Harus diinstal per platform OS, ukuran file besar, pembaharuan manual | Resource terbatas (baterai, RAM, ukuran layar), fragmentasi versi OS |
| **Contoh Aplikasi** | Tokopedia, Gmail, Web WhatsApp | VS Code, Adobe Photoshop, Spotify Desktop | WhatsApp Mobile, Gojek, Instagram |
